## Projetos Detalhados

### 1. AIVision - Aplicativo de Reconhecimento de Imagens com IA

![AIVision Screenshot](https://i.imgur.com/ZF3TEbm.png)

#### Repositório: [github.com/klebergobbi/aivision](https://github.com/klebergobbi/aivision)

**AIVision** é um aplicativo mobile de reconhecimento de imagens que utiliza modelos de visão computacional para identificar objetos, textos e cenas em tempo real, com funcionalidades offline.

#### Tecnologias Utilizadas:
- **Frontend**: Flutter, Dart, Material Design
- **IA/ML**: TensorFlow Lite, CoreML, ML Kit
- **Backend**: Firebase, Cloud Functions
- **Database**: Firestore, Local SQLite
- **DevOps**: GitHub Actions, Codemagic

#### Principais Funcionalidades:
- Reconhecimento de objetos e cenas em tempo real
- OCR (Reconhecimento Óptico de Caracteres) para extração de texto de imagens
- Detecção de faces e análise de expressões faciais
- Modo offline com modelos de ML otimizados para dispositivos móveis
- Análise de imagens com explicabilidade de AI (destaca áreas da imagem que influenciaram decisões)

#### Demonstração:
[aivision.klebergobbi.dev](https://aivision.klebergobbi.dev)

### 2. SmartHealth - Aplicativo de Saúde Preditiva com ML

![SmartHealth Screenshot](https://i.imgur.com/FQ7Jbcm.png)

#### Repositório: [github.com/klebergobbi/smarthealth](https://github.com/klebergobbi/smarthealth)

**SmartHealth** é uma aplicação móvel nativa para monitoramento avançado de saúde que utiliza machine learning para prever tendências, detectar anomalias e fornecer recomendações personalizadas.

#### Tecnologias Utilizadas:
- **Mobile**: Flutter, Swift (iOS), Kotlin (Android)
- **IA/ML**: TensorFlow, PyTorch, CoreML
- **Backend**: Firebase, Google Cloud Functions
- **Database**: Cloud Firestore, HealthKit/Google Fit integrations
- **DevOps**: GitHub Actions, Fastlane

#### Principais Funcionalidades:
- Algoritmos preditivos para detecção precoce de condições de saúde
- Monitoramento avançado de biomarcadores via sensores e wearables
- Sistema de recomendação personalizado baseado em ML para hábitos saudáveis
- Análise de padrões de sono com algoritmos de deep learning
- Detecção automática de atividades físicas com sensores de movimento

#### Demonstração:
[Vídeo demonstrativo](https://www.youtube.com/watch?v=smarthealth-demo)

### 4. MLForecaster - Sistema de Previsão para Séries Temporais

![MLForecaster Screenshot](https://i.imgur.com/UcMnhkA.png)

#### Repositório: [github.com/klebergobbi/mlforecaster](https://github.com/klebergobbi/mlforecaster)

**MLForecaster** é uma biblioteca e aplicação para previsão de séries temporais utilizando múltiplos modelos de machine learning, com capacidade de autoavaliação e seleção do melhor modelo para cada cenário.

#### Tecnologias Utilizadas:
- **Core**: Python, Scikit-learn, TensorFlow
- **Modelos**: LSTM, Prophet, XGBoost, ARIMA
- **Visualização**: Plotly, Streamlit
- **Deploy**: Docker, Kubernetes, GCP
- **IA**: AutoML, Transfer Learning
- **Interface**: Flask API, Flutter para interface mobile

#### Principais Funcionalidades:
- Ensemble automatizado de múltiplos modelos de previsão
- Interface gráfica intuitiva para visualização de resultados
- Análise de sazonalidade e tendências com explicabilidade
- Detecção automática de anomalias em séries temporais
- Ajuste automático de hiperparâmetros com técnicas avançadas de otimização

#### Demonstração:
[mlforecaster.klebergobbi.dev](https://mlforecaster.klebergobbi.dev)

### 5. VoiceAssistant - Assistente de Voz Multilíngue com IA

![VoiceAssistant Screenshot](https://i.imgur.com/VvZDVQl.png)

#### Repositório: [github.com/klebergobbi/voiceassistant](https://github.com/klebergobbi/voiceassistant)

**VoiceAssistant** é um assistente de voz inteligente para dispositivos móveis e smart speakers, com processamento de linguagem natural avançado, compatível com múltiplos idiomas e integração com sistemas de IoT.

#### Tecnologias Utilizadas:
- **Mobile**: Flutter, Swift, Kotlin
- **IA/NLP**: Transformers, BERT, Whisper
- **Speech**: TensorFlow Audio, Wav2Vec
- **Cloud**: Firebase, GCP AI Platform
- **Integração**: HomeKit, Google Home, Matter
- **Offline**: On-device inference com TensorFlow Lite

#### Principais Funcionalidades:
- Compreensão de linguagem natural em português, inglês e espanhol
- Contextualização de conversas com memória de curto e longo prazo
- Controle de dispositivos inteligentes com comandos de voz
- Resposta a perguntas complexas com busca e síntese de informações
- Personalização com aprendizado contínuo baseado em interações

## 📋 Descrição

AIVision é um aplicativo móvel de reconhecimento visual avançado que utiliza modelos de inteligência artificial para identificar objetos, textos e cenas em tempo real através da câmera do smartphone. Oferece suporte offline e tecnologia de explicabilidade AI para tornar transparente como a IA toma decisões.

### 🌟 Destaques

- Reconhecimento de imagens em tempo real sem necessidade de conexão internet
- Tecnologia de visão computacional com múltiplos modelos especializados
- Detecção e análise de texto em imagens com suporte a múltiplos idiomas
- Interface intuitiva com feedback visual de reconhecimento
- Modelos de IA otimizados para performance em dispositivos móveis

## 🖼️ Demonstração

![GIF demonstrativo](https://i.imgur.com/mZjnwQs.gif)

[Link para demo ao vivo](https://smartfinance.carlosmendes.dev)

## 🚀 Instalação e Configuração

```bash
# Clone o repositório
git clone https://github.com/klebergobbi/aivision.git

# Entre no diretório
cd aivision

# Instale as dependências do Flutter
flutter pub get

# Configure as variáveis de ambiente
cp assets/config.example.json assets/config.json
# Edite o arquivo config.json com suas credenciais de API

# Execute no dispositivo conectado
flutter run
```

## 🔧 Como usar

Para adicionar uma nova transação:

```javascript
import { addTransaction } from 'smartfinance';

// Adiciona uma transação
const newTransaction = addTransaction({
  description: 'Supermercado',
  amount: 250.75,
  date: '2025-04-09',
  category: 'Alimentação'
});

console.log(newTransaction.id); // ID da transação criada
```
